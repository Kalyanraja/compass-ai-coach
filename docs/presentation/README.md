# Presentation

`Compass-Hackathon.pptx` ("Compass: Right tool. Sharp prompt. Proven result."): 17 slides covering problem, the tagline explained, solution, architecture map, the seven-step journey, three demos, context budgeting, evidence model, privacy, security, quality, scoring-guide mapping, roadmap and hand-off.

- Every number comes from `docs/measurements.md` or `reports/eval-report.md`. Research figures cite `docs/research/evidence.md`.
- Screenshots are crops of `docs/screenshots/`. Speaker notes are on the key slides.
- The deck is generated by `scripts/build_deck.js` (pptxgenjs). The compass and people illustrations are original art drawn by `scripts/deck_art.js`. Edit the .pptx directly in PowerPoint for small changes; if you regenerate, pass a folder with the cropped screenshots and icon PNGs named in the script.
- Internal copy only: add team names on the title slide. Keep this public copy generic.
