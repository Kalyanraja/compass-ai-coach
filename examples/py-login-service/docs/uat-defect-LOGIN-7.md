# LOGIN-7: Users report they can sign in with a wrong password in UAT

> SYNTHETIC defect report for demo purposes. Not from a real tracker. No real users involved.

- **Environment:** UAT
- **Reported by:** UAT testers (synthetic)
- **Severity:** High (as reported)
- **Status:** New

## Description

Several testers said they were able to sign in even though they typed the wrong
password. It does not seem to happen every time. Some testers could not get it
to happen at all.

## Symptoms

- Sign-in sometimes succeeds with a password the tester says was wrong.
- Other wrong passwords are rejected as expected.
- No error appears in the UI when it happens.
